## Selected work

**Security**
- [**SecOps Engine**](https://github.com/frudotz/ISU-SecOps-Engine): HTTP security header analyzer with a CLI and a web GUI. Rust, Docker.
- [**Cloudflared Tunnel Auditor**](https://github.com/frudotz/ISU-SecOps-CFTunnelAuditor): checks a host's Cloudflare Tunnel setup for misconfiguration and exposure, and reports findings as CRITICAL, WARN or INFO. Shell.
- [**Nginx QUIC lab**](https://github.com/frudotz/ISU-SecOps-Nginx-RCE): penetration-testing course lab (BGT006) with a Dockerised target, the exploitation steps and the patch. Python.

**Web & infrastructure**
- [**Altyapı Sorgulama**](https://altyapi.frudotz.com) ([source](https://github.com/frudotz/net-infra-query)): Turkish broadband infrastructure lookup. Static frontend with tests.
- [**CS2 Trust Analysis**](https://cs2.frudotz.com) ([source](https://github.com/frudotz/steam-cs2-analytics)): estimates how trustworthy a Steam account looks, using several signals. Runs on Cloudflare Workers with layered abuse protection.
- [**noctera.stream**](https://noctera.stream) ([source](https://github.com/frudotz/noctera-stream)): prerendered static label site built with Vite, React and TypeScript. It ships almost no JavaScript.
